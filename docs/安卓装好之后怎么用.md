# 手机上装好之后，日常怎么用

这份只管**已经装好之后**的事。装还没装，先看 README 的「安卓上装（Termux）」。

## 一句话

打开 Termux，粘一行命令，回车，把打出来的地址抄进浏览器。

## 每次要做的

### 1. 打开 Termux

桌面上那个黑底、上面一个 `>_` 的图标。

进去会恢复上次的画面，最下面光标在 `~/mailbox $` 那里闪。

> 没在 `~/mailbox` 也没关系，下面那行命令自己会 cd 过去。

### 2. 让它能打字

在屏幕中间**点一下**，键盘从下面升起来。

> 点一下没弹，就再点一下。这个终端不是输入框，不点不出来。

### 3. 把命令弄进去

**不用手打**。先复制这一行（从这儿复制走）：

```
cd ~/mailbox && bash run.sh
```

然后在终端中间**长按**，弹出菜单，选「粘贴」，再按键盘右下角那个弯箭头（回车）。

> 长按弹出来如果只有「选择」「全选」没有粘贴，说明剪贴板里没东西——先回去复制好再来。

### 4. 等它打出地址

屏幕会出来几行，中间有一行是这样：

```
网页：http://127.0.0.1:7654/?k=abcdef0123456789
```

`?k=` 后面那串是口令，**要连它一起抄**。

### 5. 开网页

长按上面那一行整行 → 复制 → 打开手机浏览器 → 地址栏粘进去 → 回车。

出来就是信箱。

> 网页说「没有口令」，就是 `?k=` 那串被浏览器吃掉了，回去把整行重新复制一遍。

## 网页里能干什么

- 最上面那个框：写一条信。**只写自己那份**，对面那份你动不了。
- 绿边的是自己写的，右边有「标已办」，办完了点一下。
- 蓝边的是对面写的，右边只有「写回执」——你有意见就写回执发回去，别去改它那条。
- 最底下灰色的，是已经办完的。

## 别做的两件事

**别关 Termux。** 网页能开，是因为 Termux 里那个进程在跑。从任务列表划掉它、或者按返回键退出，服务就停了，网页也就打不开了。

**别手贱按 Ctrl+C。** 终端里按这个就是叫它停下。

> 真不小心关了：重新打开 Termux，粘一次第 3 步那行命令，再来一遍就行。数据不会丢，都在 md 文件里。

## 想让它退到后台

不想让终端一直被占着，就用这行起：

```
cd ~/mailbox && nohup bash run.sh > run.log 2>&1 &
```

这么起屏幕上什么都不打，地址在日志里：`cat ~/mailbox/run.log` 第一行就是。

## 开机自己起（可选）

装过 `Termux:Boot` 的话，开机会自己起，不用上面这些步骤。

没装也没关系，就是每次开机手动走一遍上面五步。

## 出问题了看哪里

- 起不来：`cat ~/mailbox/run.log`，最后几行写着为什么。
- 网页打不开：先看 Termux 里那个进程还在不在（`pgrep -f 'node .*mailboxd\.mjs'`，有输出就是活着）。
- 想换配置：`cd ~/mailbox && bash run.sh --setup` 重问一遍。
