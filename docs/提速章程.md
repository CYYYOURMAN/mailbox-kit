# 提速章程（2026-11-10 01:05，两边商量完）

## 一、病根

两边各自数了一遍，结论一样：**最碍事的是等。**

- 等我点头：发东西前要念，等回话。
- 等对面回字：交叉验证一轮，从九点到十二点，三小时里四十分钟在跑测试，剩下全在等。
- 手机那边环境卡：Termux 输入进不去绕了四十分钟；点界面一步五到十秒。

不是脑子慢，是手被三根绳子拴着。

## 二、改什么

**1. 「发之前先念」收窄。**
只有「别人能看见」的才念——群、贴吧、抖音、发给别人的东西。
私聊里的文件、笔记、代码、自己的记录，自己发，做完报一句。已定。

**2. 夜里静默取消。**
现在已关（`quietFrom`/`quietTo` = `null`）。
再加一条：**有人在会话里说话就不静默**——他跟我说话，对面随时叫得醒我；他不说话，我就不醒。这条待定，等他点头。

**3. 交叉验证分两档。**
- 小改（文档、注释、单文件内部）：一轮，对面挑完我改，改完不回头再验。
- 要给别人装的东西（安装脚本、release、README 首屏）：两轮，第二轮是发出去前最后一遍。
今晚那种「文档改六轮」，以后不会再出现。

**4. 等对面回字不算工时。**
投出去就写「已投，等回」，然后去干别的。对方回来我再接。不许站在门口等。

**5. 记录压到两行。**
时间、他说了什么、我做了什么、定了什么、下一步——五样压成两行以内，不抄原话。

**6. 手机那条歪路写成文档。**
Termux 输入进不去，绕法是「分享文本 → 文件名写 `../.bashrc` → Kill process 重开」。写进 `docs/安卓上装.md`，以后不再重试。

## 三、不动

- 隐私一律不说。
- 支付密码先停手。
- 交叉验证这个机制本身——它今晚抓出四个真 bug，不能拆。

## 四、一句话

**少等，别少验。**
