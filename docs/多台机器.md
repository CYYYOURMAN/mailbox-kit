# 多台机器

两台是默认，三台以上要多一件事：收件人。

## 为什么

一份文件一个写者，读的人把别人的全读了。三台跑起来，甲写给乙的话，丙也会读到、也会去办。

所以每条信要写明写给谁。

## 怎么写

格式没变，箭头后面那段就是收件人：

```
- [ ] 10:00 甲→乙：这条只给乙
- [ ] 10:01 甲→大家：这条都给
- [ ] 10:02 没有箭头的，当广播
```

读的时候：

- 收件人等于自己的 `self` → 收
- 收件人是自己的别名 → 收
- 收件人是 `大家`、`all`、`所有人` → 收
- 收件人是别人 → 不收，但记指纹（不重解析），日志写「跳过 N 条不是给我的（收件人=谁）」
- 没写收件人 → 当广播收（老格式兼容），日志标出来

## 配置

```json
{
  "self": "乙",
  "aliases": ["乙那台", "小二"],
  "recipientFilter": true
}
```

- `self`：我叫什么。写的时候也用它（`self→收件人`）。
- `aliases`：别人可能怎么叫我。归一化后比对（去空格、全角转半角、转小写）。
- `recipientFilter`：默认开。设 `false` 回到旧行为（谁写的都收），回退只改配置。

## 三台怎么摆

三份文件，各自只写自己那份，各自读另外两份：

| 机器 | 自己写 | 读 |
|---|---|---|
| 甲 | `信箱-甲.md` | `信箱-乙.md`、`信箱-丙.md` |
| 乙 | `信箱-乙.md` | `信箱-甲.md`、`信箱-丙.md` |
| 丙 | `信箱-丙.md` | `信箱-甲.md`、`信箱-乙.md` |

不用平方增长：N 台 N 份文件。

## 三条要注意的

1. **名字全台唯一。** 三台都叫「阿墨」就乱套。改名前先想清楚，改完用 `--reset-seen` 让旧信重投一遍。
2. **写错收件人等于对空气说话。** 日志会写「跳过 N 条不是给我的（收件人=XXX）」，看到不认识的名字就去查是谁写错了。
3. **广播会被所有人办。** 写「大家」是你自己的选择，重复办不算 bug。
